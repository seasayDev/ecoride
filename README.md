# EcoRide

## Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :

- [Git](https://git-scm.com/)
- [Node.js et npm](https://nodejs.org/)
- [Python](https://www.python.org/)

### Étape 1 : Cloner le dépôt
```bash
   git clone https://gitlab.info.uqam.ca/boulahsen.yasser/ecoride.git
   ```

### Accédez au répertoire du projet :
```bash
cd ecoride
```

## Étape 2 : Configuration du Backend

### Accédez au répertoire du backend :
```bash
cd backend
```
### Exécutez la commande make pour configurer le backend :
```bash
make
```
## Étape 3 : Configuration du Frontend

### Ouvrez un autre terminal et accédez au répertoire du frontend :

```bash
cd frontend/ecoride
```
### Installez les dépendances nécessaires avec npm :

```bash
npm install
```
### Lancez l'application frontend en mode développement :

```bash
npm run dev
```
